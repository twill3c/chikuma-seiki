# chikuma-seiki — 株式会社 千曲精機

長野県佐久市の**架空の EMS 企業**のコーポレートサイト。ポートフォリオ作品です。
同名・類似名の実在企業とは一切関係がなく、記載の設備・実績・沿革はすべて創作です。

## 何を見せる作品か

「AI で外観検査の精度を上げています」と**書く**サイトは無数にありますが、
その判定がページ上で**動く**サイトは滅多にありません。
この作品は、会社が事業として掲げている技術をサイト自身が実演します。

| デモ | 中身 | オラクル |
|---|---|---|
| AOI × AI 判定 | 生成した基板に 5 種の欠陥を仕込み、しきい値で見逃し / 過検出のトレードオフを動かす | 総当たりしきい値走査による混同行列の再計算 |
| 生産計画の最適化 | 段取り替えつきの順序付け。FIFO → 貪欲法 → 局所探索 | n ≤ 8 の全順列総当たりによる厳密最適解 |
| 部品欠品リスク | 長納期部品の発注点と安全在庫、欠品率とのトレードオフ | 閉形式 z·σ·√L |

## 制約

- **写真素材を一枚も使わない。** 図版はすべて SVG を式で描く
- **乱数を使わない。** 静的書き出しと再描画で同じ絵になる
- **完全静的。** Vercel 上でサーバ関数を実行しない
- **架空明示をテストで守る。** 番地・電話番号・認証番号の類は書けない(`src/lib/guard.test.ts`)

## 開発

```bash
pnpm install
pnpm dev
pnpm test && pnpm typecheck && pnpm build
MSYS_NO_PATHCONV=1 node harness/shot.mjs   # out/ を実ブラウザで撮る
```

仕様は `SPEC.md`、テスト方針は `TEST_SPEC.md`、作業の規律は `AGENTS.md`。
